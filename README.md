# ADM — Manual de Validación Funcional

Documentación funcional para pruebas del entorno STAGING de ADM.

Este repositorio contiene:

- manual del flujo ciudadano;
- manual del flujo funcionario;
- expediente;
- pagos y caja;
- notificaciones;
- roles y permisos;
- seguridad;
- matriz de casos de prueba;
- formato para reporte de incidencias.

> Las credenciales de STAGING se entregan mediante un canal separado y nunca se almacenan en este repositorio.
